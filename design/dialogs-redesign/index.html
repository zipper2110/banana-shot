Dialogs and windows — redesign

This folder has the new design for all modal dialogs and the two tool windows (Help and More). They use the same colors, cards, switches, segmented controls and sliders as the redesigned tabs. Each page is a working mockup over a still copy of its tab: change the values, open the color picker, and use the "Mockup state" switches at the top.

✓ No feature is added or removed. The changes are to the layout, the order, the control types and the button labels.

Changes to texts and buttons

  • Yes/No and OK/Cancel buttons become action labels: "Overwrite", "Export full video", "Cancel export", "Keep exporting", "Clear list", "Delete".
  • The general titles "Confirm", "Info" and "Transform" become specific titles, for example "Cancel queued export" and "Export started".
  • "Source video missing" (Points and Export): the title and the text change places, so the title names the problem.
  • Scoring settings: when manual scoring is on, the match format caption says "Not used in manual scoring".
  • Scoreboard style: a short line under the title tells that the video shows each change at once, and that Cancel restores the saved style. The accent color shows its hex code.
  • Analytics consent: a new line tells that the user can change the choice later in More → Privacy.
  • Help: "This tab" marks the page of the current tab.

Use the mockups

  • Open the files from the disk. They do not need a web server.
  • Add a hash to a page URL to open a state: scoring-settings.html#rules=manual, scoreboard-style.html#saved=led, color-picker.html#from=comment&view=custom, messages.html#id=ex-overwrite, help.html#tab=Export, more.html#section=About&open=fail.
  • The scoreboard drawings only suggest the 14 styles. The app draws the real styles with ScoreboardLayouts.
