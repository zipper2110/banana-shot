Export tab — redesign proposals

This folder has one main proposal and two alternatives for the Export tab. Each mockup is an HTML page with the app sidebar, the real texts and the values from the reference screenshot. Use the "Mockup state" switch at the top of each page to see the idle, running, queued and failed states.

✓ Cosmetic changes only. No feature is added or removed.

The final design combines options A and B.

  • Left, from B: the include tiles, the quality tiles with the details table, the Advanced controls, and the footer with the summary and the button.

Problems in the current tab

  1. Too many primary buttons. Each completed export has a lime "Open folder" button. On the screenshot, seven lime buttons compete with "Start export".
  2. The completed list uses too much space. Each card is about 120 px high, so the screen shows only six exports. The labels Project, Content and Video repeat on each card.
  3. The result is far from the action. The file size and the resolution are in the expanded quality card. The user must scroll up from "Start export" to see them.
  4. The settings have no clear order. The content cards, the checkboxes and the quality block have the same visual weight. There is no sign of the order in which the user makes the choices.
  5. Technical text is always visible. The GPU list and the selected encoder use five lines in the Simple tab. Most users do not need this text for each export.
  6. Weak states. "No active exports" takes a full card. A failed export and a running export look almost the same.

Design principles

One primary actionOnly "Start export" has the lime fill. "Open folder" becomes a secondary button or an icon button.
Read in orderContent → Include → Quality → Start. The layout shows this order.
Result next to the actionA short summary and the file size stay next to "Start export". They update with each choice.
Details on requestThe GPU list and the long descriptions stay available, but they have less visual weight.
Dense historyA completed export uses three lines or fewer. The file name stays the most visible text.

Options

A · Guided steps

Recommended

The left column shows three numbered steps. A fixed footer shows the output summary, the file size and "Start export". The right side keeps three panels: active export, queue and completed exports.

  • Content cards show the length and the point count on the right, so the cards are shorter.
  • The four checkboxes are one grouped list with the notes on the right.
  • Simple and Advanced are a segmented control in the step header.
  • Each quality preset shows its file size when it is closed. The selected preset opens its details.
  • The encoder and the GPU list are one line that the user can expand.
  • The running export has a large progress bar. A failed export has a red bar and a red error box.
  • Completed exports use three lines and a secondary "Open folder" button.

B · Compact tiles and one table

Alternative

The choices are tiles side by side, so the full settings column fits on one screen in Simple mode. The right side is one table. Active, queued and completed exports are row groups with the same columns.

  • Content and quality presets are three tiles in a row. The description of the selected content shows below the tiles.
  • The four checkboxes are a 2 × 2 grid.
  • The selected preset shows its details in one fixed table.
  • In Advanced mode, the encoder is a segmented control. The description of the selected encoder shows below it.
  • The table has the columns Status, File, Content, Video, Size and Time. The row buttons are icons with tooltips.

C · Accordion and history by day

Alternative

The settings are an accordion. One section is open at a time. Each closed section shows its current choice, so the user sees all choices without a scroll bar. The completed exports are grouped by day on a timeline.

  • The section headers show "Only points · 19min 41sec · 128 points" and similar summaries.
  • The four options are switches.
  • The selected preset shows its values as small value boxes.
  • "Start export" shows the file size and the encoder on a second line.
  • The running export has a progress ring with the percent in the center.
  • The completed exports have the groups Today, Yesterday and a date.

Text changes

  • The checkbox labels lose the word "Include". The group heading "Include in the video" gives this word once. Example: "Include scoreboard" → "Scoreboard".
  • "Active Exports" becomes "Active export", because only one export runs at a time.
  • The written size of a completed export shows "7.44 GB / ~7.55 GB" (A) or "7.44 GB of ~7.55 GB" (B, C). The expected size has less visual weight.
  • Option A adds one hint under "Enqueue export": "The new export waits in the queue until the current exports end." The current confirmation dialog gives the same information.
  • Option C adds one hint in the idle state: "Choose the settings on the left and start an export."

Notes

  • The colors come from UiStyles: DARK_BG, CARD_BG, LIME, GREEN and ACCENT_TEXT.
  • The mockups use the Material Symbols font from Google Fonts for the icons. Without internet access, the icons show as words.
  • The file sizes in the mockups change with the content, the cards and the bitrate. The formula is an estimate for the mockup only.
  • Add #state=queue&quality=advanced to a page URL to open it in a given state.
