Share tab — mockups

The Share tab (B-46 in docs/backlog.md) makes a YouTube thumbnail for the open project. Each mockup is an HTML page with the app sidebar and real frames of the doubles match. Use the "Mockup state" switch at the top of each page to see the other states.

Final · Layout styles

Current

The base is option A: the preview at the left, the edit fields at the right. Changes from the review of 2026-10-15:

  • The thumbnail is the only product. The description is not on the tab.
  • No scoreboard on the thumbnail. Six layout styles under the preview: Big words, Versus, Match card, Split, Broadcast, Poster. Each style has its own placement and colors.
  • Each style card shows the current frame and texts, so the user compares the styles at once.
  • The fields have preset values. Each field tells where its preset comes from. A field that the style does not use is gray.
  • The side column has two tabs: Texts and Colors. The preview and the Save block (with the small YouTube preview) are always visible. Only the tab content scrolls.
  • Colors: one system of six color roles for all styles. A color set gives a value to each role. The user can then change each role with a swatch or any color.

Changes from the review of 2026-10-17:

  • Zoom: the user can zoom into the frame (100 to 200 %) and drag the preview to move it, so that the players are larger. All styles use the same frame, zoom, and position.
  • Moment: a strip of 10 frames of the point replaces the slider. A click or a drag on the strip sets the exact moment. Two buttons and the arrow keys move one frame back or forward.
  • Text position: each style has two positions (Left or Right, Bottom or Top for Broadcast). Poster has one position. The switch is above the style cards, because it belongs to the style. No position puts a text in the bottom-right corner.
  • Final score: a choice under "Large words". The user must select it. The default words never show the score, because many users do not want to show the result.
  • Zoom limit: 150 % for a 1080p video, 200 % for 4K. The frame always has at least 1280 px of the video, so it stays sharp.
  • Save block: one line for each video type ("Saved yesterday 21:35", "changed since", or "not saved"). The file name is only in the tooltip. "Save thumbnail" becomes "Replace thumbnail" when the file exists. "Open folder" selects the file.
  • The project stores the Share settings. The mockup state "Reopened project" shows them.
  • Small texts: a note in the Save block tells the user when a text is less than 32 px in the PNG. At the width of YouTube search, such a text is less than 9 px high.

Decided on 2026-10-17

A file name for each video type …-full-match.png and …-best-points.png. One name makes the second save replace the first.
The project stores the Share settings The video type, the point, the moment, the zoom and its position, the style, the text position and the colors of each style, the edited texts, and the time of each saved file. When the user opens the project again, the tab shows the same thumbnail. If the stored point is not in the project any more, the app uses the default point.
No file name in the Save block The user needs to know if the file is saved and where it is. A line for each video type and "Open folder" (it selects the file) tell this. The long file name is only in the tooltip.
The colors and the position stay with each style, also for the next project A color set, a role change, or a text position applies to the current style only. "Use the style colors" goes back to the default set. The app keeps the last style, its colors, and its position for the next project, because a channel needs the same look on all videos. The texts do not go to the next project. The final score is never kept.

States in the final mockup

  • First thumbnail: "League or event" is empty. The styles do not show it.
  • Long names: the texts become smaller to fit. Broadcast puts each team in its own row. A note tells the user that short words are easier to read.
  • No favorites: the video type is "Full match", and the app selects a point near the middle of the match.
  • Reopened project: the tab shows the stored settings and the two saved files. The button is "Replace thumbnail".
  • 1080p video: the zoom stops at 150 %. A hint tells why.
  • Frame read error: the preview shows a message. "Save thumbnail" is disabled.

A hash in the URL sets more states, for example final.html#layout=split&place=right or #zoom=1.5.
