Stats tab — redesign proposals

This folder has one main proposal and two alternatives for the Stats tab. Each mockup is an HTML page with the app sidebar, a frame of the sample video and a simulated three-set match. The mockups work: select a set, select the rows for the video, change the point length limits and the card transparency, and move the pointer on the chart. Use the "Mockup state" switch at the top of each page to see the gray rows, the coverage note, a one-set match and the empty states.

✓ Cosmetic changes only. No feature is added or removed.

Final design

Selected

The final design uses option B as the base, with these changes from the review:

  • The Match / Set control comes from option C, with the set score under each set name. It is under the table header with the player names, above the momentum chart, and it uses the full width of the left side. The tab has no header row. A one-set match has no Match / Set control.
  • The "In video" column comes from option A. It is the last column of the table, next to the card column. It has a light lime background from the table header to the last row, and a selected row has a stronger background.
  • Each row and the momentum chart have a checkbox in the "In video" column, in place of the chips of option B.
  • Each group title shows the count of selected rows in the "In video" column, for example "2 of 4" (option A).
  • The left side and the card column have the same width. The table columns grow and shrink with the window, and the chart draws again at the new width.
  • "In video" for the momentum chart is off by default. The card does not show the chart until the user selects it.
  • The default rows in the video are Points won, Points won on serve, Service games won, Break points won, Short points won, Long points won and Match duration. The card shows the 7 rows on one page.
  • The default point length limits change: a short point lasts 10 s or less (now 7 s), and a long point lasts 13 s or more (now 15 s). The row tooltips do not name the ATP shot ranges any more, because the new limits do not match them.
  • "Duration" is now "Match duration". It is the time from the start of the first point with a winner to the end of the last point with a winner. It is not the length of the video, and points without a winner at the start or at the end do not count. The row has a help icon with this text.
  • The hint "Select Match or a set above the score" of option B is removed. The segmented control does not need it.

Swing effort
Medium. Each row is a custom panel with a painted bar and a fixed column layout. The lane background is a painted column behind the last cell of each row. The header uses the segmented control of the other tabs.

Problems in the current tab

  1. The scope control looks local. The names, the score and the Match / Set buttons are above the left column only. But the scope also changes the chart and the card preview on the right. The buttons use the default Swing toggle look, not the segmented control of the other tabs.
  2. Two jobs mix in one table. The tab has two jobs: read the statistics, and select the rows for the video. The "In video" checkboxes are the first column, before the labels, with a small caption. The table reads as a check list first. The momentum chart has its own "In video" checkbox in a different place.
  3. The table does not compare. The two value columns have the same weight. The user must read each pair of numbers to see who leads. The video card shows bars for this, but the tab does not.
  4. Gray rows hide the reason. A gray row shows "—" in both columns. The reason is only in the tooltip of a small info icon.
  5. Controls look like data. The point length limits are a line between the group title and the rows. They look like one more row.
  6. The coverage note is easy to miss. It is plain yellow text under the scope buttons.
  7. The card column is text-heavy. The help is one paragraph of four sentences. The page count shows only in the pager, and a card with one page shows no count.

Design principles

Scope on topThe Match / Set control is above everything that it changes: the table, the chart and the card.
Read first, then selectThe label and the values come first. The "In video" control has one fixed place and one look, for the rows and for the chart.
See who leadsThe value of the leading player is brighter. The mockups use the same numbers as the bars of the video card. There is no new calculation.
Say whyA gray row shows its reason. The text is the text of the current tooltip.
Controls look like controlsThe point length limits are a tool bar with steppers, not a table row.

Options

A · Scope bar and card panel

Recommended

A header strip across the full tab shows the players, the set scores and the scope control. Under it are two panels: "Statistics" on the left and "In the video" on the right. The "In video" column is the last column of the table, so it is next to the card panel.

  • The scope is a segmented control with the caption "Show the statistics of". It is hidden for a one-set match, as now.
  • The "In video" column has a light lime background from the header to the last row. The momentum checkbox is in the same column.
  • Each group title shows how many rows of the group are in the video, for example "2 of 4".
  • The main value ends at the middle of its column and the detail starts there, so the numbers align. The leading value is white and has an underline in the player color.
  • A gray row shows its reason in place of the two "—" values.
  • The point length limits are a tool bar with steppers under the group title.
  • The card panel shows chips with the card title and "6 rows · 2 pages". The pager has page dots. The help is three short lines with icons.

B · Rows like the card

Alternative

Each row uses the layout of the video card: the value of player 1 on the left, the label and the bar in the middle, the value of player 2 on the right. The score is a small scoreboard, and its column buttons select the scope.

  • "Match" is a wide button above the set buttons. The selected set columns of the score get a lime frame.
  • The "In video" control is a chip with a film icon at the start of each row. A selected row has a lime edge and a dark green background.
  • The bar in each row uses the same numbers as the bar on the card. The leading value is white.
  • A gray row shows its reason in the place of the bar.
  • The pager buttons show the text "Previous page" and "Next page". The help is in a "How the card works" section that the user can close.

C · Wide chart and page strip

Alternative

The momentum chart uses the full width of the tab, so each point has more space. Under the chart, the groups are cards in two columns, and the card preview stays at the right. Page thumbnails replace the page buttons.

  • The scope control shows the set score under each set name.
  • The "In video" controls are switches: at the start of each row, and in the chart header.
  • Each group card has its own player columns and the count of rows in the video.
  • The point length limits are a tool bar at the top of the Point length card.
  • The page thumbnails show each page of the card. The chart page has the label "Chart". A click shows the page in the large preview.
  • Gray rows stay as now: a gray label, an info icon with the reason in the tooltip, and "—".

Text changes

  • All options: a gray row can show its reason as visible text. The text is the same as the current tooltip. Example: "Mark the server of one point in the Scoring tab."
  • All options: the group title shows the count of rows in the video, for example "2 of 4" (A) or "2 of 4 in video" (B, C).
  • A adds the caption "Show the statistics of" before the scope control, the pane title "Statistics · Full match", and the hint "Select In video for the rows that the card shows."
  • A adds the chips "Match statistics" and "6 rows · 2 pages" to the card panel. The card title is the same text that the card shows.
  • B adds the hint "Select Match or a set above the score. The table, the chart and the card show the selected part of the match." The page buttons show their tooltip text as the label. The slider has the end labels "Solid card" and "More video".
  • C shows "All sets" under "Match" and the set score under each set name. The thumbnails have the hint "Click a page to see it."
  • The help text of the card stays the same in all options. A and B split it into lines.

Notes

  • The colors come from UiStyles: DARK_BG, CARD_BG, LIME, GREEN, ACCENT_TEXT and YELLOW. The player colors are the colors of the Scoring mockups.
  • The card preview uses the sizes and the page split of StatsCard: 7 rows on each page, a group stays on one page when possible, and the chart is the last page.
  • The match is simulated: 6-4 3-6 7-6 with a tiebreak. The statistics come from the simulated points. They are not from a real project.
  • The mockups use the Material Symbols font from Google Fonts for the icons. Without internet access, the icons show as words.
  • The actions that open the Scoring tab show a short message in the mockup.
  • Add #mode=gray&scope=2 to a page URL to open it in a given state. The modes are normal, gray, coverage, oneset, noscore, noproject and error.
