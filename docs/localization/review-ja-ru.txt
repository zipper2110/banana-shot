# 1. Маркеры в фигурных скобках, например {name}, {count}. Приложение подставляет вместо
#    них значения. Не переводите их и не меняйте. Порядок маркеров в японском тексте может
#    отличаться от русского. Проверьте, что в японском тексте есть все маркеры из русского.
#    Список маркеров и их значений — ниже, в разделе «МАРКЕРЫ».

# 2. Множественное число: {count, plural, one {…} few {…} many {…} other {…}}.
#    Приложение выбирает вариант по числу. Знак «#» внутри варианта — это само число.
#    В японском языке у существительных нет множественного числа, поэтому в японском тексте
#    есть только вариант other: {count, plural, other {# ポイント}} = «# очков» для любого
#    числа. Это правильно. Проверяйте только текст внутри other {…}.
#
# 3. «\n» — перенос строки. «\n\n» — пустая строка между абзацами.
#    Текст между «**» и «**» приложение показывает жирным.
#
# 4. Стиль японского текста:
#    - Предложения — в вежливой форме です/ます: «選択してください» (выберите), «保存されます»
#      (сохраняется).
#    - Кнопки и пункты меню — короткие существительные или короткая форма глагола: «保存»
#      (сохранить), «フォルダーを開く» (открыть папку).
#    - Кавычки — японские 「…」. Название кнопки или вкладки внутри предложения — в 「…」:
#      «「スコアを修正」をクリックします» (нажмите «Изменить счёт»). Названия с словом タブ
#      (вкладка) — без кавычек: «ポイントタブ».
#    - Знаки препинания — полноширинные: «、», «。», «（…）», «？», «！». Двоеточие после
#      подписи — обычное «: ».
#    - Между числом и единицей-словом стоит пробел: «3 ポイント», «{seconds} 秒», «2 MB».
#      Имена по умолчанию — без пробела: «プレイヤー1» (Игрок 1), «ペア1» (Пара 1).
#    - Слова катаканой с долгим звуком — в современной форме Windows: «フォルダー» (папка),
#      «ブラウザー» (браузер), «ユーザー» (пользователь).
#
# 5. Клавиши: «Space», «Delete», «Enter», «Esc», «Shift» — по-английски, как на клавиатуре.
#    Клавиши со стрелками — знаками «←», «→», «↑», «↓» (в русском — словами «Влево» и т. д.).
#
# 6. Слово «розыгрыш» и слово «очко». В русском тексте «розыгрыш» — отмеченная часть видео,
#    а «очко» — единица счёта. В японском языке оба слова — «ポイント». Это обычное слово в

Выберите стиль под просмотром. Каждая карточка стиля показывает ваш кадр и ваши тексты в этом стиле. = プレビューの下でスタイルを選択します。各スタイルのカードには、そのスタイルでのフレームとテキストが表示されます。
Меняйте тексты на вкладке «Тексты», а цвета — на вкладке «Цвета». = テキストは「テキスト」タブで、色は「色」タブで変更します。
Выберите «Сохранить обложку». Приложение записывает PNG размером 1280 × 720 в папку экспорта. = 「サムネイルを保存」を選択します。アプリは 1280 × 720 の PNG をエクスポートのフォルダーに書き込みます。
Выберите «Итоговый счёт» в поле «Крупные слова», чтобы показать счёт матча. По умолчанию приложение никогда не показывает счёт. = 試合のスコアを表示するには、「大きな文字」の下で「最終スコア」を選択します。既定でスコアが表示されることはありません。
Выберите «Вернуть шаблоны», чтобы убрать ваши изменения текстов. = テキストの変更を取り消すには、「プリセットを使う」を選択します。
Выберите «Слева» или «Справа» («Сверху» или «Снизу» для стиля «Трансляция») над карточками стилей, чтобы переместить тексты. = テキストを移動するには、スタイルのカードの上で「左」または「右」（Broadcast では「上」または「下」）を選択します。
На вкладке «Цвета» выберите набор цветов, затем при необходимости измените каждый цвет. «Авто» делает текст тёмным или белым, чтобы он читался. = 「色」タブでカラーセットを選択し、必要に応じて各色を変更します。「自動」は、テキストが読みやすいように暗い色または白にします。
Выберите «Цвета стиля», чтобы вернуть цвета стиля. = スタイルの色に戻すには、「スタイルの色を使う」を選択します。
Выберите «Открыть папку», чтобы открыть папку экспорта. Если файл существует, папка откроется с выделенным файлом. = エクスポートのフォルダーを開くには、「フォルダーを開く」を選択します。ファイルがある場合は、ファイルを選択した状態でフォルダーが開きます。
У полей есть шаблоны из проекта: имена игроков, тип матча, заголовок табло как корт и дата видеофайла. «Лига или турнир» сохраняет текст вашей последней обложки. = 各項目には、プロジェクトからのプリセットが入ります: プレイヤー名、試合の種類、コートとしてスコアボードのタイトル、動画ファイルの日付。「リーグまたは大会」には、前回のサムネイルのテキストが残ります。
Пустое поле не показывается на обложке. Вкладка «Тексты» показывает только поля выбранного стиля. Остальные поля сохраняют свои тексты для других стилей. = 空の項目はサムネイルに表示されません。「テキスト」タブには、選択したスタイルの項目だけが表示されます。ほかの項目のテキストは、ほかのスタイル用に残ります。
Кадрирование, поворот и цветокоррекция применяются к кадру, как при экспорте. = トリミング、回転、色の調整は、エクスポートと同じようにフレームに適用されます。
Масштаб останавливается, когда в кадре остаётся меньше 1280 пикселей видео: на 150 % для видео 1080p и на 200 % для видео 4K. = フレームの動画が 1280 ピクセルより少なくなると、ズームは止まります。1080p の動画では 150%、4K の動画では 200% です。
У каждого типа видео свой файл, например «…-best-points.png». Повторное сохранение заменяет файл. Блок сохранения показывает, когда вы сохранили каждый файл и изменилась ли обложка с тех пор. = 動画の種類ごとに別のファイルがあります（例: 「…-best-points.png」）。もう一度保存すると、ファイルが置き換わります。「保存」のブロックには、各ファイルを保存した日時と、その後サムネイルが変更されたかどうかが表示されます。
Маленький просмотр над «Сохранить обложку» показывает обложку с длиной видео. Поиск YouTube показывает её немного крупнее. В PNG нет значка длины, потому что YouTube добавляет его сам. Приложение не ставит текст в правый нижний угол. = 「サムネイルを保存」の上の小さいプレビューには、動画の長さ付きのサムネイルが表示されます。YouTube の検索結果では少し大きく表示されます。長さのバッジは YouTube が追加するため、PNG にはありません。右下の角にはテキストを置きません。
Подсказка сообщает, если текст длинный или мелкий. Текст меньше 32 пикселей в PNG трудно прочитать в поиске YouTube. = テキストが長い場合や小さい場合は、メモでお知らせします。PNG で 32 ピクセルより小さいテキストは、YouTube の検索結果では読みにくくなります。
YouTube принимает обложку не больше 2 MB. Если в кадре много мелких деталей, приложение делает кадр немного мягче, чтобы файл остался меньше 2 MB. = YouTube で使えるサムネイルは 2 MB 以下です。フレームに細かい部分が多い場合は、ファイルが 2 MB 未満になるように、フレームを少しやわらかくします。
Проект запоминает настройки обложки. Следующий проект начинается с вашего последнего стиля, его цветов и положения текста. = サムネイルの設定はプロジェクトに保存されます。次のプロジェクトは、前回のスタイル、その色、テキストの位置で始まります。
