# 1.1.0

The items of `backlog.md` that are done in this release.

### B-14 Padel

- Support padel matches. `padel.md`, section "Baseline", describes what the
  app does. The next tasks are in B-45.

### B-12 Themes

- The user can select the Dark, Mid, or Light theme and a custom accent
  color in More → Settings. The Projects tab shows the theme switch before
  the first project.

### B-37 Locate a moved source video

- Finding F-02 of the feature audit of 2026-10-05.
- When the source video of a project is moved or renamed, the user can
  select the video again with "Locate video...". The project then opens,
  and the manifest keeps the new path.

### B-41 Admin dashboard for the numbers

- The cockpit (`cockpit-worker/`) shows the downloads, the site numbers, and
  the app analytics. It is not a part of the app package.
- The decisions and the tasks are in `docs/cockpit/b-41-tasks.md`.

### Analytics schema 3

- The extended statistics also send the theme, the accent, the language, and
  the sports of the projects (`analytics-contract/v1/attributes.json`).
  Notice version 2 (B-44) on the privacy page describes this data.
