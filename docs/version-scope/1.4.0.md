# 1.4.0

The items of `backlog.md` that are done in this release.

### B-63 Scoreboard start and end settings, and a preview that stays while marking

- Problem (user report, 2026-10-31): the Points tab preview hides the
  scoreboard 20 s after the last marked point. While the user marks the
  next point, the scoreboard goes away and then comes back. The preview and
  the "Full video" export now use the same timeline
  (`ScoreboardTimelineBuilder`, `fullVideo = true`), so the export rule
  also hides the board in the editor.
- Current behavior of the "Full video" export (2026-10-30): the scoreboard
  starts at the first scored point and fades in. After the last point it
  shows the final score for 20 s and fades out. The fade is 0.5 s.
- Decided on 2026-10-31:
  - Add two settings to the scoreboard settings dialog:
    - Start: First point (the default), Video start, or Fixed time.
    - End: Hide at once, 5 s, 10 s or 20 s after the last point (the
      default is 20 s), Until the video ends, or Fixed time.
  - Fixed time: a time field (`mm:ss`) and a "Use the current position"
    button. The button takes the preview position when the dialog opens.
    Do not use the word "playhead" in the texts.
  - A fixed time belongs to the video of this project. "Use as my default"
    does not keep it. If the default has "Fixed time", a new project uses
    First point or 20 s.
  - If the fixed start is after the fixed end, the dialog shows an error
    and does not save. A fixed time after the video end means "Until the
    video ends".
  - A fixed start after the first point, or a fixed end before the last
    point, is allowed. Then some points have no board. The dialog shows a
    short hint, not an error.
  - The preview with the default end (a time after the last point):
    - The match has not ended by the score: the board stays until the
      video ends. This is also true for "Sets, no match end".
    - The match has ended by the score (`matchEnded`), also with points
      after the match end: the board ends as in the export.
  - The preview with "Until the video ends" or a fixed time: the board
    follows the setting exactly, also while the user marks points.
  - The export always follows the settings. An incomplete markup with the
    default end hides the board 20 s after the last point.
  - The fade stays 0.5 s and has no setting. There is no fade at the video
    start or the video end. The preview shows no fade.
  - The "Only points" and "Only favorites" exports ignore these settings.
  - With a trim (B-62), "Video start" and "Video end" mean the trim start
    and the trim end.
- Tests: the preview cases (match not ended, match ended, points after the
  match end), each start and end option in the export timeline, the fixed
  time validation, and the default that drops a fixed time.
- Done when: the user can set the start and the end in the scoreboard
  settings, the export follows them, and the preview keeps the board while
  the user marks points of a match that has not ended.

- Done on 2026-10-31:
  - `ScoreboardSettingsV1` has `start`, `startMs`, `end` and `endMs`. A
    file without them gets First point and 20 s after the last point.
  - `ScoreboardTimelineBuilder.fullVideoRange` gives the range of the
    board. The "Full video" export gives it the video length, so "Until
    the video ends" and a fixed time after the video end have no fade.
  - `ExportTrim.overlays` removes the fade where the trim cuts the board.
  - The default scoreboard settings (`forDefault`) have no fixed time.
  - The Scoreboard settings dialog has the group "Start and end". It shows
    a red error for a time that is not valid and for a fixed start after
    the fixed end. Then Save is not available.
  - The Points tab buttons are now "Scoring rules" and "Scoreboard
    settings".
  - Tests: `ScoreboardTimingTest`, `ScoreboardTimeTextTest`.
