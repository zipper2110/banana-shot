# 1.4.1

The items of `backlog.md` that are done in this release.

Decided by the author on 2026-11-15: the version number is 1.4.1. The
release notes, the changelog, the "What's new" page, and the `notes` of
`release/version-policy.json` do not tell about the paid features.

### B-68 Point details (advanced scoring), with B-72 and B-73

- Tennis only. The concept and the status are in
  `docs/point-details/b-68-point-details.md`.
- In Scoring rules → Scoring mode, the user selects Basic or Advanced
  (B-73). A new project opens Scoring rules one time.
- In advanced mode, the point bar has a second row with the ending
  buttons: ace, winner, forced error, and unforced error. X records a serve
  fault, and L records a let. The start button shows the serve number.
- The Stats tab and the statistics card show the aces, the double faults,
  the serve percentages, the winners, and the errors of each player. The
  scoreboard shows a "2nd serve" mark during a 2nd serve.
- The option "Ask error kind" asks where the ball went after an error
  (net, long, or wide). The strip keeps its space, so the video does not
  move (B-72).
- The Export tab has the option "Serve faults and lets" for "Only points"
  and "Only favorites". The option does not show for "Full video".
- The help page "Advanced scoring" is new.
- Open: the checks in the running app (section "Checks in the running
  app" of the concept). Check 3 is done.

### B-67 Crash evidence

- The plan and the status are in `docs/crashes/b-67-crash-evidence.md`.
- The app finds a crash of the previous session. It keeps the safe part of
  the JVM crash file in `logs/crashes`. A watchdog writes a thread dump when
  the UI does not answer for 10 seconds.
- After a crash with evidence, the next start shows a popup. The popup
  opens the feedback form with the crash summary and the log.
- New essential counters: crash type, crash library, and crash activity.
  The analytics contract, the analytics Worker, and the cockpit have the
  new keys. The notice version stays 3, and the schema stays 4.

### B-13 macOS fixes

- The app does not crash at sleep with an open video (4f80366, a7709de).
  The mpv previews close before a sleep and load again after the wake.
- In full screen, the mpv window stays on the Space of the app (68f89f8),
  and it stays in its place after a wake (1ad1f03).
- The user can drag a comment by its text (f9174b7).

### B-38 T6 Show a failed save of the adjustments

### Other changes since 1.4.0

- Statistics card: card styles, a compact card, group titles, and a light
  card (04dace8).
- Share tab: the thumbnail group "Simple" with 5 styles (Score box,
  Underlined, Serif, Headline, and Labels) and the Graphite color set
  (0340d04).
- Comments: the free styles Plain, Shadow, and Bold (7e47662).
- Export: the computer does not go to idle sleep while an export runs.
  More → Settings has the switch "Keep the computer awake during exports".
  It is on by default (12e93cf).
- Points tab: the points list is narrower (300 px), so the video gets more
  width. The point rows have no Replay button. The Replay button of the
  playback bar opens the replay editor (7b70e12).
- Dialogs: each dialog stays in the screen height, so the buttons stay
  visible (066e323).
- Clicks: a click works when the pointer moves a little between the press
  and the release (ef13835, 1450f66, 3524c7a).
- The keys of the Points tab work at once after the Edit dialog closes
  (f3f5f0c).

### Paid features in the code (not in the release notes)

- The comment styles Glow, TV label, and Bubble (P-1) and the comment
  animations Fade, Pop, and Slide up (P-3) are in the code. They have
  `paid = true`. The release build is the free version: it does not show
  them and draws them as Outline and with no animation.
- Only `--paid` or `-Dbananashot.paid=true` turns them on
  (`docs/backlog-paid.md`). The release workflow and the installers do not
  give them. The help texts do not name them.
- Do not name these features in the release notes, the changelog, the
  "What's new" page, or the `notes`.

### Changelog of 1.4.1 (draft)

Write this text into `site/public/changelog/index.html` at the release
(release checklist, step 9). Use it also for the GitHub release notes.
Read it again before the release.

- Tennis: advanced scoring. In Scoring rules &rarr; Scoring mode, select
  Advanced, and record how each point ended: an ace, a winner, a forced
  error, or an unforced error. X records a serve fault, and L records a
  let. The Stats tab and the statistics card show the aces, the double
  faults, the serve percentages, the winners, and the errors of each
  player. The scoreboard shows a "2nd serve" mark. Turn on "Ask error
  kind" to record where the ball went: net, long, or wide.
- Statistics card: select a card style. A compact card shows more rows on
  each page. You can also show the group titles and use a light card.
- Thumbnails: the new group "Simple" has 5 styles and a new color set.
- Comments: the new styles Plain, Shadow, and Bold.
- Export: the computer does not go to sleep while an export runs. You can
  turn this off in More &rarr; Settings.
- Crashes: after a crash, the next start shows a popup. You can send a
  report with the details of the crash in one click.
- Points: the points list is narrower, so the video is larger.
- Fixes: the dialogs fit on small screens. Clicks on the project list and
  on the color squares do not get lost. On macOS, the app does not crash at
  sleep with an open video, and the video stays in its place in full
  screen.
