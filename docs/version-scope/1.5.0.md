# 1.5.0

The items of `backlog.md` that are done in this release.

Decided by the author on 2026-11-18: the version number is 1.5.0. The
release notes, the changelog, the "What's new" page, and the `notes` of
`release/version-policy.json` do not tell about the paid features
(`docs/paid-features.md`).
Also decided on 2026-11-18:

- The author tested B-49 with their own videos. B-49 is in 1.5.0.
- The Theme card is the first card of More → Settings. This change is in
  1.5.0.
- The release notes name the ratings (B-77) as experimental.

### B-49 A match from several video files (free)

- The "New project" dialog accepts several files of one match (3dc1efe).
  "Add videos…" adds files at the end of the list, also from other
  folders. The user can move a file up or down (f79a54c).
- The preview plays the files as one timeline (an mpv EDL file). The export
  joins the parts with the concat filter.
- Files with different formats get a warning. Its button opens the
  feedback form with the formats of the files.
- When a file is missing, the app asks for it.
- The projects table and the project card show "N videos" and a list of
  the files (f79a54c).
- The VIDEO track of the Points timeline shows one block for each file
  (76c31ad).
- The FAQ answer "Can I use a video from any phone or camera?" has the
  sentence about several files (bef7629). Deploy the site only after the
  release.

### B-75 Export preview (free)

- The Preview button of the Export tab opens a window that plays the
  export result with libmpv before the encode (f83c0e1).
- Not checked on macOS (T7 in `docs/export-preview/b-75-tasks.md`).

### B-76 More serve and return statistics

- Free: the row "Tiebreaks won" in the Overview group.
- Paid (advanced mode): 1st and 2nd serve return points won, unreturned
  serves, and the ending "Unreturned serve" (key Z).

### B-77 Performance ratings (experimental)

- Free: the group "Ratings (experimental)" with Overall, Serve, Return,
  and Pressure from the basic data.
- Paid (advanced mode): Attack, Consistency, and the advanced inputs of
  Serve and Return.

### Other changes since 1.4.1

- Statistics: "Deuce games won" replaces "Deuce points won". No-ad tennis
  and beach tennis show "Deciding points won", and padel keeps "Golden
  points won" (2b7a9b9).
- Statistics: the rows "Most points in a row", "Most games in a row", and
  "Largest point lead" are removed. The momentum chart stays (39a8e5a).
- Replays: the still frame stays on one exact frame in the Points tab,
  the editor, pick mode, and the export (12ca7bf).
- More → Settings: the Theme card is the first card, and the Language card
  comes after it.

### Paid features in the code (not in the release notes)

- B-69: the point filter of the export (92c2457, 561636d).
- B-68: in advanced mode, no point starts until the server is known.
  Enter is the point start key in the texts (1293bee).
- The paid rows of B-76 and B-77 (above).
- Do not name these features in the release notes, the changelog, the

### Changelog of 1.5.0 (draft)

Write this text into `site/public/changelog/index.html` at the release
(release checklist, step 9). Use it also for the GitHub release notes.
Read it again before the release.

- A match from several video files: in "New project", select all files of
  the match, or click "Add videos…" to add files from other folders. You
  can change the order of the files. The app plays and exports them as one
  video.
- Export preview: in the Export tab, click Preview to play the result
  before the export starts. You can see the points, the scoreboard, the
  comments, the replays, and the cards.
- Statistics: experimental player ratings from 0 to 10 (Overall, Serve,
  Return, and Pressure). The new row "Tiebreaks won".
- Statistics: "Deuce games won" replaces "Deuce points won". The rows
  "Most points in a row", "Most games in a row", and "Largest point lead"
  are removed.
- Settings: the Theme card is now the first card.
- Fixes: the still frame of a replay stays on the same frame in the
  preview and in the export.
