Changelog

The changes in each version. The newest version is at the top. The files of each version are on the GitHub releases page.

1.1.0

Release date: coming soon

  • Padel: score padel matches with two teams. The deuce can be advantage, golden point, or star point. Americano matches count a fixed total of points. The scoreboard shows the teams, and the statistics use a padel court.
  • Themes: you can select a dark, mid, or light theme and your own accent color in More → Settings.
  • Projects: when the match video is moved or renamed, you can find it again with "Locate video..." and continue the project.
  • Extended statistics (only if you turn them on) also send the theme, the language, and the sports of your projects. See the privacy notice.

1.0.0

Release date: 2026-10-06

The first public version.

  • Projects: import a match video and continue later from the list of recent projects.
  • Points: mark the start and the end of each point, mark favorites, and add comments to the video.
  • Scoring: give each point to a player. The app counts the score for many match formats and shows the server.
  • Statistics: serve, break points, point length, and a momentum chart. A statistics card and set summaries in the video.
  • Colors and Transform: light and color controls, zoom, move, and rotate.
  • Export: the full match, only the points, or only the favorites, with the scoreboard and the comments. Hardware encoders from NVIDIA, AMD, and Intel. An export queue.
  • Feedback form in the app. Anonymous usage statistics: essential statistics on by default (you can turn them off), and extended statistics only if you turn them on.
  • Update check and "Update and restart".
