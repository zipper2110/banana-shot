Download BananaShot

BananaShot is free. You do not need an account.

Download for Windows All files of the release
The file is BananaShot-win-Setup.exe. It comes from the GitHub release of the newest version.

System needs

Operating systemWindows 10 or Windows 11, 64-bit
Disk spaceUnder 1 GB for the app, and more for your videos
Video filesMP4, MOV, MKV, AVI, M4V, and WMV
Faster exportOptional: a graphics card with a video encoder from NVIDIA, AMD, or Intel. Without it, the app uses the software encoder. It is slower, but it works on all PCs.
Administrator rightsNot necessary. The app installs only for your Windows account.

macOS and Linux are not available now.

Install

  1. Download BananaShot-win-Setup.exe and open it.
  2. Windows can show the message "Windows protected your PC". The setup file is signed, but BananaShot is new, and Windows trusts a new app only after many downloads. Click More info, then click Run anyway.
  3. The setup installs the app and starts it. You can find BananaShot in the Start menu.

Smart App Control. The app is signed, so it also works when Smart App Control is on.

Updates

The app checks for a new version when it starts. When a new version is available, the app shows a notice. Click Update and restart. The app downloads the new version, installs it, and starts again. Your projects and settings stay.

Each version works for 6 months after its build date. From 30 days before this date, the app shows a warning. Install the newest version to continue. The FAQ tells why.

Uninstall

Open the Windows Settings, then Apps, then Installed apps. Find BananaShot and select Uninstall.

The uninstall keeps your projects and settings. They are in the folder %APPDATA%\BananaShot. To remove them too, delete this folder. Your videos and exported videos stay where you saved them.

Source code and license

The source code is on GitHub. BananaShot is source-available software under the Elastic License 2.0. The app also contains FFmpeg, libmpv, and a Java runtime. Each of them has its own license. The list is in the file THIRD-PARTY-NOTICES.txt of the app, and in More → About.
