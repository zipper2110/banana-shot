Privacy notice

This page tells which data the BananaShot app and this site collect, why, and for how long.

In short. The app edits your videos on your PC. It never sends your videos. The app sends data only in these cases:

  • Usage statistics: essential anonymous statistics, on by default (you can turn them off), and extended statistics only if you select them.
  • Feedback reports: only when you click Send in the feedback form.
  • Version check: a request for a small file on GitHub, with no user data.

This site counts visits without cookies. See This site.

Usage statistics

Notice version 1. Effective from: 2026-10-06.

BananaShot sends anonymous usage statistics. There are two levels:

  • Essential statistics are on by default. They tell us how many people use the app, how often, and which versions. Without them, we cannot know if anyone uses the app at all. You can turn them off at any time.
  • Extended statistics are optional. They also tell us which parts of the app people use and how well exports work. The app sends them only if you select "Send extended" at the first start, or turn on "Send extended statistics" in More → Privacy.

No level sends your videos, file names, project names, or text that you type. No level identifies you or your computer.

When the app sends

The app sends one short summary of the current session: at the start, every 5 minutes if something changed, and at exit. Each new summary of a session replaces the previous one on the server.

Essential statistics (on by default)

Each summary contains these items:

  • A random session ID. The app makes a new ID for each session and keeps it only in memory. The ID does not identify you or your computer, and it does not link two sessions.
  • The level of the summary (essential or extended).
  • The app version and the OS family (Windows, macOS, Linux, or other).
  • The number of the summary in the session, and if it is the last summary.
  • The session length in seconds, and the seconds while the app window was active.
  • The version of this notice.
  • These counts:
    • A range for the number of sessions on this computer (1, 2 to 5, 6 to 20, or more than 20). Thus we can tell new users from users who come back, without a user ID.
    • Errors that the app did not expect. The app sends only the number, not the error.
    • If the previous session did not close normally.

Why the essential statistics are on by default: BananaShot is a small project. These numbers are the only way for us to know if people use the app and if a new version is stable. They are a legitimate interest of the author (GDPR Article 6(1)(f)). We keep them to the minimum: they contain no feature use and nothing about your videos or projects. You have the right to object (GDPR Article 21): turn them off as described below.

Extended statistics (optional)

If you select the extended statistics, the summary also contains these counts. The extended statistics need the essential statistics.

  • The tabs that you open with a click, and the active seconds on each tab (Projects, Points, Colors, Crop/Rotate, Scoring, Stats, Export).
  • Projects created and opened, and videos that could not open.
  • Points added, deleted, and marked as favorites. Comments added. Point outcomes recorded in Scoring.
  • Changes of the colors, and changes of the crop or rotation.
  • Help windows opened.
  • Exports for each encoder type (software, NVIDIA, AMD, Intel): started, completed, failed, cancelled, and interrupted at exit. The total export time and the total video length of the completed exports, in seconds. The failures by cause (source missing, output not writable, process start, encoder error, other). The export options in use (scoreboard, comments, stats card, favorites only, idle trim). The output size (720p, 1080p, 1440p, 2160p, or other).

The legal basis of the extended statistics is your consent (GDPR Article 6(1)(a)). You can withdraw it at any time.

What the app does not send

Your videos, audio, or frames. File names, folder names, or paths. Project names, player names, scores, or comments. Text that you type. A user ID, a device ID, or an install ID. Error messages or log files. The clock time, the time zone, or the language of your computer.

Where the data goes

The app sends the summary over HTTPS to our server on Cloudflare (a Cloudflare Worker). Cloudflare processes the data for us. The server stores the summary in a Cloudflare D1 database in the EU jurisdiction. The server keeps the receive times only to the hour.

Your IP address

Cloudflare receives your IP address to deliver the request. The server does not store it. To limit the number of requests, the server keeps a keyed hash of the address for one hour.

How long the data stays

A daily job deletes each session 90 days after its last summary.

How to turn off the extended statistics

Open More → Privacy and turn off "Send extended statistics". The app then deletes the extended counts of the current session at once. Its next summary contains only the essential statistics and replaces the extended counts of this session on the server. The summaries of earlier sessions stay until the 90 days end. We cannot delete them on request, because no value links a summary to you.

How to turn off all statistics

Open More → Privacy and turn off "Send essential statistics". This also turns off the extended statistics. The app then stops at once and sends nothing more, also after a restart. It deletes the counts of the current session. The summaries that the server already has stay until the 90 days end. We cannot delete them on request, because no value links a summary to you. The app works the same without statistics.

Feedback reports

You can send a problem, an idea, or a question to the author from the app: the Feedback button in the sidebar, the "Report this problem" button of an error message, the "Tell us" link at the end of each help page, or More → Contact.

When the app sends a report

The app sends a report only when you click Send in the feedback form. The usage statistics choice does not change this. If you do not send a report, the app sends no feedback data.

What a report contains

  • The topic (problem, idea, question, or other) and your message.
  • A random report ID that the app makes for each report.
  • The app version, the name and version of Windows, and the Java version.
  • Your email address, only if you give it. The author can reply only to this address. The app keeps it on your computer for the next report. You can delete it in the form.
  • The text of the error message, only if you open the form from an error message. You can remove it before you send.
  • The last 2 MB of the log files of the app, only if you select "Attach the log files". The log files contain the names and folders of your videos and projects. They do not contain your videos. Before you send, "Show the data" shows the exact data that the app sends.

Where a report goes

The app sends the report over HTTPS to our server on Cloudflare (a Cloudflare Worker with a Cloudflare D1 database). The server sends the report to the author with a Telegram bot. Thus, Telegram also processes the report.

How long the data stays

  • The server keeps the report text, the topic, the email address, the app data, and the error text for 90 days. Then a daily job deletes them.
  • The server does not keep the log files. It sends them to Telegram and drops them.
  • Cloudflare receives your IP address to deliver the request. The server does not keep it. To limit the number of reports, the server keeps a keyed hash of the address for one hour.
  • The copy in the Telegram chat of the author stays until the author deletes it.

How to ask for deletion

Write to the contact address. Give the report ID, or the date and the text of your message. The app shows the ID after the send. The author then deletes the report on the server and in the Telegram chat.

Version check and updates

This section is separate from the usage statistics. The app reads a small file from GitHub when it starts and from time to time while it runs. The file tells if this version still works and if a new version is available. The request sends no user ID and no usage statistics. GitHub receives your IP address and the standard data of a web request. "Update and restart" downloads the setup file of the new version from GitHub. You cannot turn off the version check, because each version stops working after a time.

This site

Cloudflare hosts this site. Cloudflare receives your IP address to deliver the pages.

The site counts visits with Cloudflare Web Analytics. It does not use cookies or other storage on your device, and it does not follow you to other sites. It records the page address, the address of the page that sent you here, the browser and the device type, and the country. We see only totals, not single visitors.

The download button opens a file on GitHub. GitHub then receives your IP address and the standard data of a web request.
